# Installing Pianobar on Your Phone

The compiled APK file **`pianobar.apk`** is located in this artifacts folder.

### Installation Steps

1. **Download `pianobar.apk`** from the artifacts panel to your phone or computer.
2. If downloaded on a PC/Mac, transfer `pianobar.apk` to your phone via USB cable, Google Drive, or messaging.
3. Open the file on your Android phone using your **Files** or **Downloads** app.
4. If Android asks for permission to install apps from this source, tap **Settings** and toggle **Allow from this source**.
5. Tap **Install** and then **Open**.
6. When prompted, allow notification permissions so that the lock screen playback controls and background streaming service can function properly.

---

### What's Included

- **Material 3 Interface**: High quality vinyl artwork, animated audio visualizer, scrubber, and station chips.
- **Authentic CLI Console**: Terminal interface with ASCII art, live logs, interactive prompt, and quick shortcut keys (`p`, `n`, `+`, `-`, `t`, `b`, `e`, `s`, `h`).
- **Lock Screen & Notification Controls**: Play/pause, skip, like (`+`), and dislike/ban (`-`) directly from your notification tray and lock screen.
- **Background Playback**: Dedicated Android Foreground Service with audio focus management.
