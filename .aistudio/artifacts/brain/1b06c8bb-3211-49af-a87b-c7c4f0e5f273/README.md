## Key Features Included

- **Material 3 Interface**: High-resolution album artwork, dynamic equalizer visualizer waveform, and station selector chips.
- **Authentic CLI Terminal Mode**: Monospace retro terminal with the original Pianobar ASCII header, live color-coded event stream, interactive command prompt (`>_`), and keyboard shortcut bar (`p`, `n`, `+`, `-`, `t`, `b`, `e`, `s`, `h`).
- **Lock Screen & Notification Controls**: Play, pause, skip tracks, and like / dislike (`+` / `-`) directly from the Android notification bar and lock screen without opening the app.
- **Background Audio Streaming**: Dedicated foreground playback service with audio focus handling (ducks/pauses on phone calls).
- **Music Genome Project**: Inspect why any track was selected with detailed acoustic, harmonic, and vocal characteristics (`e` / Info dialog).
